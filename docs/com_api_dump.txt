【组分添加】
    Components.Add("Methane") 成功
    Components.Add("Water") 报错：HRESULT=-2147352567 —— 组分名必须来自 HYSYS 组分库（水的库名为 "H2O"，"Water" 非法）
    Components.Add("H2O") 成功
    确认：Component List - 1 当前 Count=2，Names=('Methane', 'H2O')
【物性包设为 Peng-Robinson】
    官方属性：FluidPackage.PropertyPackageName（Help → Customization Guide（本机为 xhysys.chm 的 FluidPackage 对象页）：“Property Get/Let PropertyPackageName As String”，dispid 1610874881）。配套只读对象：FluidPackage.PropertyPackage（Get PropPackage），其 TypeName 为 HYSYS 内部类型名（Peng-Robinson -> "pengrob"）。
    正确写法（必须在 Basis 变更模式内写入，否则 E_ACCESSDENIED）：
      bm = case.BasisManager
      bm.StartBasisChange()
      fp.PropertyPackageName = "Peng-Robinson"
      if bm.CanEndBasisChange: bm.EndBasisChange()   # 提交 Basis
    本次读取（空白 Case 新建 FP）：抛错 HRESULT=-2147352567，inner=0x80004005（FluidPackages.Add() 建出的 FP 初始不含物性包）
    本次写入：写入 'Peng-Robinson' 抛错 HRESULT=-2147352567，inner=0x80070057
    写入 'PR' 抛错 HRESULT=-2147352567，inner=0x80070057（说明 "PR" 不是可用的注册基名）
    本次 CanEndBasisChange = False
    结论（V15 实测边界）：
      1) 属性名与写法如上；名称必须用注册基名，“UNIQUAC - Ideal”这类带后缀的显示名不可写，"PR"/"Ideal" 等别名报 E_INVALIDARG。
      2) Basis 模式外直接写 -> E_ACCESSDENIED 0x80070005；StartBasisChange 后写有效包名 -> 成功并立即读回。
      3) 可在同族内切换：UNIQUAC(活度系数) -> NRTL 成功；Peng-Robinson(EOS) -> SRK 成功；跨族切换（UNIQUAC -> Peng-Robinson）被拒 E_INVALIDARG。
      4) 对 FluidPackages.Add() 新建的空白 FP（无物性包）写任何包名都是 E_INVALIDARG，且 CanEndBasisChange 恒为 False —— V15 无法仅用 COM 从零建立可用 basis；SimulationCases.Add(name, Type) 的 Type 参数被忽略（传路径/'Template'/'Blank'/1 均无效）。
      5) 因此推荐路径：先用一个已含目标物性包的 case 作模板（SimulationCases.Open），再改组分、清流程、建模；或先在 GUI 里建好含 Peng-Robinson 的空白模板保存复用。
    对照实测（自带示例 K-101.hsc）：原 PPN='Peng-Robinson'，TypeName='pengrob'
      Basis 模式外：写入 'SRK' 抛错 HRESULT=-2147352567，inner=0x80070005
      StartBasisChange 后：写入 'SRK' 调用成功，读回 'SRK'
      CanEndBasisChange = True
      （验证后不保存关闭；空白新 case 可用此法：打开含 Peng-Robinson 的模板再建模）
【MaterialStream 温度/压力/流量的单位机制】
    本次实测 温度：SetValue 抛错 HRESULT=-2147352567（E_ACCESSDENIED 0x80070005：空白 Case 无物性包、basis 不完整，流股变量被锁定；此时 GetValue 返回 -32767，即 HYSYS 的空值标记）
    本次实测 压力：SetValue 抛错 HRESULT=-2147352567（E_ACCESSDENIED 0x80070005：空白 Case 无物性包、basis 不完整，流股变量被锁定；此时 GetValue 返回 -32767，即 HYSYS 的空值标记）
    本次实测 流量：SetValue 抛错 HRESULT=-2147352567（E_ACCESSDENIED 0x80070005：空白 Case 无物性包、basis 不完整，流股变量被锁定；此时 GetValue 返回 -32767，即 HYSYS 的空值标记）
    在 basis 完整的 Case 上的已验证实测（示例 Case，Water Feed 流股，显示单位集 °C/kPa/…）：
      T.SetValue(30,'C') -> GetValue('C')=30.0, GetValue('K')=303.15, .Value=30.0
      P.SetValue(1,'bar') -> GetValue('bar')=1.0, GetValue('kPa')=100.0, .Value=100.0
      T.Value=25 直接赋值 -> GetValue('C')=25.0（按显示单位 °C 解释）
      只读侧：T .Value=23.889=GetValue('C')（显示单位 °C，而非内部单位 K=297.04）
    结论：SetValue(value, 单位字符串) / GetValue(单位字符串) 支持自动换算（证据见上方 RealVariable dump 中的 GetValue/SetValue 方法）；裸 .Value（读和直接赋值）使用 Case 当前显示单位集，不是固定内部单位。被求解器计算的变量（CanModify=False）不可写。实践建议：读写一律用 SetValue/GetValue 显式指定单位字符串，避免依赖当前显示单位集。
